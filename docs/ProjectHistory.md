# 项目进展与历史记录

这里按日期倒序整理原 README 的更新提示和项目进展，并补充后续修订的文档入口。同一天的条目合并在同一节，保留当时的证据和限制。

**这是历史记录，不是当前运行状态清单。** 测试数量、设备在线情况、账户错误、配置和部署结论都对应条目所述的日期与版本；不能据此判断今天的服务或模型可用性。自动测试数量、模型置信分数与真实仪器准确率是不同指标。`PROVEN` 只表示列明范围的检查已经完成，`PARTIAL_EVIDENCE` 表示只覆盖部分环节，`NOT_PROVEN` 表示仍缺少对应验收。

当前功能概览见 [README](../README.md)，升级约束以 [运行可靠性说明](RuntimeReliability.md#升级入口) 为准。原图、数据库和原始验证回执保留在本机，不随 Git 分发。

## 2026-09-14 · 多二维码、GPU OCR 与证据留存

- 支持场景、仪器 A/B 同时或独立关联，视频持续 GPU OCR，按实验台与仪器分类留存。参数、去重及准确率边界见 [多二维码与实时视频 OCR](多二维码与实时视频OCR.md)。
- NAS 全量索引支持实验员、日期、仪器与版本筛选；新增每日照片和回执完整性巡检、异常报告与重启续期。
- 优化连续照片调度，最多四张照片独立等待，GPU 保持串行，视觉请求仍限一次一个；历史页面新增全部读数分页、照片缩略图、逐阶段耗时和 NAS 归档状态。
- 语音照片识别解除绑定前置条件，监控间隔和稳定等待均为 0.5 秒，模型启动预加载，保存逐阶段时延。本机已补处理 24 张实际语音照片并核验 NAS 原件及回执哈希；当时视觉模型因账户 `Arrearage` 无法调用，新照片端到端时延和实际读数准确率待验证。
- 增加本机事务归档队列、NAS 照片与版本回执留存、断线补传和可直接打开的中文索引。103 项自动测试通过，涵盖绑定起止、OCR 结果与原件关联；实际仪器语音读数验收仍待现场测试。
- 仪器码支持直接自动绑定，场景扫码证据独立记录；工作台显示原始命中帧，操作记录纳入未绑定的扫码和面板读数。桌面工作台按窗口高度同屏布局。94 项自动测试通过，现场仪器 A 的二维码已成功解码，新的自动绑定现场闭环仍待验收。
- 按需切换本机 GPU OCR，增加独立 GPU 依赖锁、设备检查、准确的设备回执和实际 GPU 验证入口。见 [GPU 部署](GPU部署.md)。
- 增加本机后台自动运行、首次实验员登记和持久化暂停／恢复。74 项自动测试通过；隔离浏览器关闭超过 23 秒后仍完成样张扫码绑定。使用方法见 [本机自动运行](本机自动运行.md)。
