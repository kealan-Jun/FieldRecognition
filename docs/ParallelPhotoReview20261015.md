# 照片并行初读与云端复核（2026-10-15，待部署）

同一张照片同时交给本地 OCR 和已配置的云端视觉模型。本地初读可靠保存后立即可见并进入归档队列；云端完成后推进同一任务的结果版本，更新原事件目录的 Result/Readings，不创建第二次采集或更换拍摄时间、二维码、绑定快照。原图、初读、云端回答及不可变回执版本保留。

## 配置与执行

保留既有 `FIELD_VISION_PROVIDER`、启用开关、模型、密钥和显示规则，只显式选择：

```dotenv
FIELD_VISION_PHOTO_MODE=parallel
```

默认仍为 fallback；primary 继续使用原视觉优先规则。parallel 仅处理照片，视频维持原有本地优先/条件兜底。配置从应用启动时的快照读取，不热改线上配置或已加载的源码。

未绑定照片直接并行读取请求范围，输出待核对候选。绑定照片先执行一次授权面板定位，再把同一定位快照交给两路识别，避免从整图背景数字猜仪器归属。这个共同前置步骤也计入处理耗时；两路不要求等待对方的识别数值。定位缺失时云端只恢复未归属候选。局部裁剪完整性和原有数值、单位、精度、归属规则继续校验。

本地模型调用仍串行；最多四张照片由原有请求调度推进，云端使用独立的四线程池并受原提供方锁约束，实际请求同时最多一个。parallel 为每张照片/每个授权面板主动安排云端请求，不使用 fallback 的五秒触发和三十秒冷却，调用量可能增加。线程池排队和提供方槽位等待仍会影响复核延迟；不额外引入定时等待，也不在一次提供方调用内自动重试。

## 当前结果与复核规则

| 字段 | 含义 |
| --- | --- |
| `reading_mode=parallel_photo` | 本次任务采用并行流程 |
| `result_available=true` | 当前投影可读；running 时也可展示初读 |
| `result_stage` | preliminary 初读，或 reviewed 已应用云端结果；两者均非人工确认 |
| `result_revision` / `result_updated_at` | 同一任务当前投影的版本和更新时间 |
| `first_result_at` | 本次任务首次发布结果的时间；后续复核不改写 |
| `parallel_review.status` | running、completed、failed、conflict、unreadable 或 cancelled |
| `local_ocr` / `fallback` | 两路原始输出、失败与逐面板证据 |

本地先完成时，任务保持 running 和原租约，初读持久化后展示并优先归档；不会为了提前展示把任务误标为已结束。云端结果通过校验时原位替换当前值。单位/精度/字段角色冲突时保留相应初读并标记待核对。云端明确看不清时撤下相应当前有效数值，初读原文继续留在证据中；网络/API 失败则保留初读并说明复核未完成。

云端先完成时可先交付，迟到的本地结果只补入原始证据，不替换已经交付的云端结果。任务失去租约后不能发布旧复核；绑定失效/任务取消不由云端恢复，已在途的请求回执仍保留。人工确认仍使用原草稿流程，collecting 阶段不能确认；已确认正式记录保持不可变。

网页在同一结果区域更新。Agent 调用方每秒查询同一 `get_panel_result(job_id)`，遇到 running 且 result_available 时显示初读并继续轮询；根据 result_revision 更新原读数位置，在终态结束。工具说明已同步此协议，外部聊天/Agent 的实际编辑能力仍需其调用方接入。旧客户端只等 completed 时仍能读取最终结果，但无法获得初读体验。

## 归档、测量与验证边界

初读进入现有本地事务 outbox，最新可用初读与终态结果共享优先发布规则及历史公平配额。归档服务异步推进；展示初读不代表 NAS 已成功留存。已绑定结果仍用原六字段 Result，阶段和审计信息位于 Evidence/Readings/Readme。未绑定候选不生成假身份 Result。归档原件校验、重试、不可变历史和人工确认规则继续执行；同路径派生结果更新沿用既有发布机制。

新增 `run_to_first_result_ms`、`write_to_first_result_ms`；后者依赖来源写入时间，保留原时钟依据。已有总处理、OCR、云端调用/槽位等待和归档发布计时继续记录；共用定位耗时与并行阶段不能重复累加。首次网页可见、复核完成和另一台 NAS 客户端首次可读是不同指标。

开发使用隔离工作树、项目现有解释器、临时 SQLite、合成照片和本地归档替身，不访问真实模型、相机或 NAS，不读取/写入真实凭据。临时验证材料预算 2 GiB，保留 pytest 最近三次运行，不复制真实数据集。测试验证并发开始、两种完成顺序、同任务替换、初读归档、同目录 Result 更新、失败、冲突、租约与模型无关的启动/资源契约。
