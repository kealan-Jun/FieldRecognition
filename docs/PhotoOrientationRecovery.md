## 处理边界

仅在存在拍摄时有效仪器绑定、原方向检测成功但候选为零的非视频照片上尝试逆时针 90°、180°、270°。旋转发生在内存中，源 JPEG、采集时间、绑定有效期和历史回执保持原样。原方向已有候选、未绑定照片和视频沿用原路径。

检测分数和数字合理性不选择正向。当前显式双窗口模型需要完整水平配对、原生红色字符几何及唯一支持方向；LCD 等面板需要附近非数字字母在两个源视图中空间及文本一致。视图可为原生上下文、二倍上下文或同方向整图；整图文字必须落在同一面板上下文内。此检查是方向启发式，不是经现场标定的正确率保证。

方向竞争保留 `ambiguous / competing_directions`，证据不足为 `unconfirmed / source_direction_unconfirmed`，没有授权旋转面板为 `no_authorized_rotated_panel`。存在授权旋转候选却不能选方向时，`failure_reason=panel_orientation_unconfirmed`；旧 `skip_reason` 保持兼容，完整原因见 `photo_orientation`。

方向证据按仪器隔离，A 的证据不授权同图 B。模型清单的显式实例映射和拍摄时绑定共同限制归属；品牌文字不赋予身份，通用类型仍需实例证据，唯一绑定不替代它。本批照片未解码出二维码，不声称照片二维码确认了仪器身份。

每张符合条件的照片最多新增 **3 次面板检测请求、15 次 OCR 请求**，检测器既有内部多视图策略不变。共享定位和方向检查先完成，再让本地与云端读取相同正向源裁剪；准备好的定位不会重复检测或重复方向 OCR。保存每次检测、文字视图、源 BGR 像素哈希、空间支持、实际调用数与耗时，仍使用部署配置指定的现有模型、设备和提供方。
